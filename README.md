## Что это

Одно нажатие — и готово. Выберите категорию, скажите или напишите вопрос — ИИ сам подстроит ответ. Никаких промптов, никакого обучения.

- **9 категорий под любую задачу** — бизнес, программирование, медицина, экономика, репетитор, дети, тренер, психолог и обычный режим. ИИ сам выбирает стиль: ребёнку объяснит на игрушках, бизнесмену — с цифрами, программисту — кодом с комментариями.
- **Голосовой ввод** — не умеете печатать? Нажмите микрофон и говорите.
- **Работает без ограничений** — автоматически обходит блокировки провайдеров.
- **Всё на устройстве** — чаты хранятся только в памяти телефона. На серверы уходит только email при регистрации.
- **Сохранение ответов** — экспорт в TXT, MD, JSON, HTML.
- **Тёмная тема** — комфортно днём и ночью.

## Запросы

20 запросов в день — бесплатно.
